# Лига лидеров: краткая логика игры

Игра моделирует управление консалтинговым бизнесом в течение года. Команды получают клиентские ситуации по кварталам, выбирают управленческие решения и отражают последствия в Excel-бюджете.

## Роли

- **Капитан команды** заходит в Telegram-бота через `/start`, автоматически занимает первую свободную команду и отвечает за решения команды.
- **Организатор** ведёт игру из админки: открывает этапы, видит статусы команд, может повторно отправить этап или принять решение за команду.

## Цикл этапа

1. Организатор открывает этап.
2. Бот отправляет капитанам текущую ситуацию и варианты решения.
3. Капитан выбирает вариант и подтверждает его.
4. Бот просит отправить Excel-файл бюджета.
5. После загрузки файла команда становится готовой к следующему этапу.

## Ветки сценария

- **Красные команды** идут по ветке клиента «Якорь»: скидка, найм/подрядчики, перенос выручки, рост зарплат и новая клиентская возможность.
- **Синие команды** идут по ветке «Шахта → Вышка → Птица»: скидка, крупный проект, три последовательных Q2-решения, кризис по трудоёмкости и последствия для нового клиента.

## Что смотрит админ

- Подключился ли капитан.
- Доставлен ли этап в Telegram.
- На каком этапе и в каком статусе каждая команда.
- Какое решение выбрано.
- Загружен ли Excel и можно ли его скачать.
